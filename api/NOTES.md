## Decisions worth remembering

- **The prompt is copied, not retyped.** `SYSTEM_PROMPT` was generated by slicing plan.md
  and asserting equality byte for byte. If the plan's prompt changes, bump `PROMPT_VERSION`
  and rerun `scripts/analyze.py` for every committed `analysis.json`.
- **The Anthropic client is lazy.** `api.analysis.client` starts as `None` and is built by
  `get_client()` on first use. That is why `/api/health` can answer without a key and
  without constructing a client, and it is still the one attribute tests monkeypatch.
- **`analyze()` catches narrowly.** Only `anthropic.APIError` and unparseable output become
  `ModelError`. Anything else propagates so it lands on `internal` (500), not `model_error`.
- **The token bucket only guards the model call.** It is taken at step 6, so a malformed
  body, an unknown scenario, or a bad id never spends a token.
- **`load()` validates the id before touching disk**, so a scenario id can never walk out
  of `data/scenarios`.
- **Two extra safety nets beyond the contract's two handlers**: the analyze route wraps its
  own body so nothing escapes as a FastAPI default, and a `StarletteHTTPException` handler
  turns an unrouted URL into an `ErrorResponse` (`bad_request` under 500, `internal` at or
  above it) rather than `{"detail": "Not Found"}`.
